# Football Game Takeover

**Minecraft** × Football Game · visual · idea by the team

Bring Football Game into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned Minecraft into a football stadium: red and blue players charge you, and my football field goals count points. The crowd goes wild.

## Install

Copy the mod jar into your Fabric mods folder for Minecraft Java 26.3 with Fabric API. Start a world: a stadium builds around you. Right-click the football to throw it at the players or through the goalposts.
